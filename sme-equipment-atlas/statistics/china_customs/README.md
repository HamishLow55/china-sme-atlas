# China Customs: Semiconductor Equipment Imports

Source: GACC online statistics query platform, <http://stats.customs.gov.cn/> (English: `/indexEn`). Official PRC trade statistics. Every query needs a CAPTCHA, so pulls are manual; do not automate CAPTCHA solving.

**Geography:** goods declared on entry to mainland China's customs territory. This covers **all fabs located in mainland China, including foreign-owned fabs.**

## Files

| File | Grain | Notes |
|---|---|---|
| `imports_hs8_monthly.csv` | period × hs8 (all origins, all provinces) | 11 codes, six 848640xx codes and 90308200, 2021-01 → 2026-09. `cny` is held for 2022–2025 only |
| `imports_hs8_partner_province_monthly.csv` | period × hs8 × partner × province | **Filtered**: 8 origins × 14 provinces only (see `queries.csv`). The 11 codes cover 2021-01 → 2026-09 and 91–94% of annual value; 848610xx covers 2023-01 → 2026-09; 848640xx covers 2021-01 → 2026-09 and 74–84% of annual value; 90308200 covers 2021-01 → 2026-09 |
| `queries.csv` | one row per raw export | sha256, flow, currency, interface, period, groupings, codes present, row count, `pulled_on`, `notes` |
| `codes_hs8.csv`, `partners.csv`, `provinces.csv` | code lists | Portal labels verbatim, with a Chinese and/or English name depending on which interface was used |
| `raw/` | portal CSV exports, unchanged | GB18030 encoding |

Every file except `raw/` and the manual columns of `queries.csv` is generated by `python3 -m atlas statistics-build`.

**Columns:**

| Column | Meaning |
|---|---|
| `period` | `YYYY-MM` |
| `hs8` | 8-digit Chinese tariff code (stored as text) |
| `partner_code` | Customs 3-digit country code (for imports: **country of origin**, not vendor nationality or shipping country) |
| `province_code` | 2-digit code of the **consignee's registered location** (收发货人注册地), not necessarily the fab site |
| `quantity_items` | First quantity (台 / "Number of item") |
| `weight_kg` | Second quantity (千克 / kg) |
| `usd`, `cny` | Value as reported in each currency, where that currency was pulled |
| `query_ids` | Raw export(s) the row came from |

  | 84862021 | CVD |
  | 84862022 | PVD |
  | 84862029 | Other deposition |
  | 84862031 | Step-and-repeat lithography |
  | 84862039 | Other lithography |
  | 84862041 | Plasma dry etch |
  | 84862049 | Other etch and strip |
  | 84862050 | Ion implant |
  | 84862090 | Other front-end apparatus |
  | 90314100 | Optical inspection of wafers and masks |

  The sum of these 11 codes reproduces UN Comtrade's HS6 848620 + 903141 import totals (checked by `statistics-check`).
- **8486.40xx, mask making, assembly and handling** (pulled 2026-09-28; labels are the portal's English names, shortened):

  | Code | Content |
  |---|---|
  | 84864010 | Manufacture or repair of masks and reticles |
  | 84864021 | Plastic encapsulation (molding) for semiconductor/IC assembly |
  | 84864022 | Wire bonders |
  | 84864029 | Other mounting and bonding machines (Note 11(C)) |
  | 84864031 | Automated material handling in IC factories (AMHS) |
  | 84864039 | Other lifting, handling, loading or unloading of boules, wafers, devices, ICs and flat panels |

  The six codes reproduce Comtrade's HS6 848640 import total, within 0.06% for 2021–24 and 0.29% for 2025. The 2025 gap reflects the two pulls' different dates (portal 2026-09-28, Comtrade 2026-09-23); `statistics-check` allows 0.5% for this heading. 84864039 mixes wafer handling with flat-panel handling. Customs declaration examples also show wafer-transfer robots imported as tool modules ([8486403900 examples](https://www.transcustoms.cn/China_HS_code.asp?HS_Code=8486403900)).
- **90308200, instruments for measuring or checking semiconductor wafers or devices** (pulled 2026-09-29). This is where ATE, test handlers and wafer probers are declared: US rulings [N280220](https://rulings.cbp.gov/ruling/N280220) and [N337433](https://rulings.cbp.gov/ruling/N337433), plus Chinese declaration examples. It also holds LED, solar and laboratory testers. Its totals match Comtrade HS6 903082 within 0.27% for 2021–23 and 2025. 2024 is 1.6% ($10m) below Comtrade, which is unexplained; `statistics-check` allows 2% for this code. Annual imports of $0.5–0.8bn look low relative to foreign ATE vendors' China sales. Some test equipment is likely declared as parts (90309000) or under 90318090, so treat this code as a floor for test imports.
- **8486.10xx, wafer and boule manufacture:** 84861010 crystal growth, 84861020 grinding, 84861030 sawing, 84861040 chemical-mechanical polishers ("for the manufacture of boules or wafers"), 84861090 other.

## Query recipe (portal)

1. Set 进口/出口 (import/export) and **美元 (USD)**. Check the currency on every query: it can silently revert to 人民币.
2. **Set the year first, then the end month, then the codes.** Changing the year resets the end month to 1 and clears the code box.
3. Tick 分月展示 (monthly breakdown).
4. Grouping fields (up to four): 商品 (commodity), 贸易伙伴 (partner), 收发货人注册地 (registered province), 贸易方式 (trade mode), 关别 (customs district), 运输方式 (transport mode).
5. Paste codes comma-separated with no spaces. One query takes all 23 codes: the 2026-11-02 pull combined them, 4,002 rows, with no truncation.
6. Export. The Chinese interface gives `数据导出.csv`, the English one `downloadData.csv`.

Raw file names must follow `<M|X>_<year>_<MM-MM>_monthly_<groupings>[_suffix].csv`, e.g. `M_2025_01-12_monthly_hs8_partner_province.csv`. The file itself records neither flow nor query, so the name carries them.

## Facts to know before using these tables

- **One year per query.** Recent months sit in a faster "active" database; older queries warn and run slower.
- **Codes are limited to 8 digits.** 10-digit sub-lines (e.g. lithography by light source) cannot be queried.
- **CNY is not a fixed conversion of USD.** Customs' implied CNY/USD rate varied by 0.3–2.6% across codes within a single month, in the 2025 and January–August 2026 pulls compared in both currencies. Do not convert with one monthly rate. The January–August 2026 CNY pull left `raw/` when its quantities were revised, and no project reads the column.
- **CMP is declared under more than one code.** Examples published on a customs-classification site show Applied Materials Reflexion LK declared under 8486104000, and Reflexion SS-3000-AR and Ebara FC-3000 under 8486209000 ([8486104000 examples](https://www.transcustoms.cn/China_HS_code.asp?HS_Code=8486104000), [8486209000 examples](https://www.transcustoms.cn/China_HS_code.asp?HS_Code=8486209000)).
- **Units are declared units** ("items"); they may be whole tools or modules.
- The portal's own totals are revised. Values here are as of `pulled_on`. Between the September 2026 pulls and the 2026-11-02 pull, 14 of 144 January–August monthly code totals changed in USD, a net +$2.2m on $26.15bn. The largest was 84862029 in August 2026, +$2.1m (+2.2%). Refresh the whole year rather than adding one month, because a single-month file would disagree with the months already held.
